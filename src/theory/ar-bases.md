## Практикум: системы счисления

### Перевод из десятичной в двоичную

Делим число на 2, записываем остатки, читаем их **снизу вверх**:

| Деление | Частное | Остаток |
|---|---|---|
| 78 : 2 | 39 | **0** |
| 39 : 2 | 19 | **1** |
| 19 : 2 | 9 | **1** |
| 9 : 2 | 4 | **1** |
| 4 : 2 | 2 | **0** |
| 2 : 2 | 1 | **0** |
| 1 : 2 | 0 | **1** |

Снизу вверх: $78 = 1001110_2$. Проверка: $64 + 8 + 4 + 2 = 78$.

### Из двоичной в десятичную

Каждая единица весит $2^k$, где $k$ — номер разряда справа, начиная с нуля: $1011_2 = 8 + 0 + 2 + 1 = 11$.

### Шестнадцатеричная и восьмеричная

Одна шестнадцатеричная цифра — ровно 4 бита, восьмеричная — 3 бита. Поэтому двоичное число разбивают на группы **справа**:

| Двоичное | По 4 бита | 16-ричное | По 3 бита | 8-ричное |
|---|---|---|---|---|
| `1001110` | `100 1110` | `4E` | `1 001 110` | `116` |
| `11111111` | `1111 1111` | `FF` | `11 111 111` | `377` |

Цифры 16-ричной системы: 0–9, затем A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.

### Системы счисления в C

```c
int x = 78;
printf("%d %X %x %o\n", x, x, x, x);   /* 78 4E 4e 116 */

int a = 0x4E;     /* 16-ричный литерал: 78 */
int b = 0116;     /* ВНИМАНИЕ: ведущий 0 — восьмеричный литерал, тоже 78! */
int c;
scanf("%x", &c);  /* прочитать 16-ричное число: введи 4E */
```

> [!warning] Ведущий ноль меняет систему
> `int n = 010;` — это **8**, а не 10: литерал с ведущим нулём восьмеричный. Не дописывай нули «для красоты».

Для двоичной системы спецификатора в `printf` нет — двоичное представление печатают сами:

```c
/* печать 8 младших битов числа x (от старшего к младшему) */
int i;
for (i = 7; i >= 0; i--) {
    printf("%d", (x >> i) & 1);    /* i-й бит: сдвиг вправо и маска 1 */
}
```

Сдвиги `>>` и маски `&` подробно разобраны в уроке «Операции с целыми: маски и сдвиги».
