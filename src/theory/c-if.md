## Условие в C — это число

В C нет отдельного «логического» результата в старом стиле: **0 — ложь, любое другое число — истина**. Операции сравнения возвращают `1` (истина) или `0` (ложь).

| Операция | Смысл | Операция | Смысл |
|---|---|---|---|
| `==` | равно | `!=` | не равно |
| `<` `>` | меньше, больше | `<=` `>=` | не больше, не меньше |
| `&&` | И | `\|\|` | ИЛИ |
| `!` | НЕ | | |

```c
int x = 5;
printf("%d %d %d\n", x > 3, x == 4, !(x > 3));   /* 1 0 0 */
```

## `if` и `else`

```c
if (условие) {
    /* выполняется, если условие истинно */
} else {
    /* выполняется, если ложно */
}
```

Цепочка «если — иначе если»:

```c
if (mark >= 90) {
    printf("отлично\n");
} else if (mark >= 75) {
    printf("хорошо\n");
} else if (mark >= 60) {
    printf("удовлетворительно\n");
} else {
    printf("неудовлетворительно\n");
}
```

Условия проверяются **сверху вниз**, выполняется первая подходящая ветка. Поэтому во втором условии не нужно писать `mark < 90` — это уже известно.

> [!tip] Всегда ставь фигурные скобки
> Без скобок к `if` относится только **одна** следующая команда. Добавишь вторую строку — она будет выполняться всегда. Скобки `{ }` даже для одной строки спасают от этой ошибки.

## Ловушки условий

```c
if (x = 5)          /* ОШИБКА: присваивание! Условие всегда истинно */
if (x == 5)         /* правильно: сравнение */

if (x > 0);         /* ОШИБКА: точка с запятой — пустой if, */
{                   /* а блок выполняется всегда */
    printf("plus");
}

if (0 < x < 10)     /* ОШИБКА: сначала (0 < x) даёт 0 или 1, и это всегда < 10 */
if (x > 0 && x < 10)   /* правильно */

if (a / 3.0 == 0.1) /* ОШИБКА: вещественные нельзя сравнивать на точное равенство */
if (fabs(a / 3.0 - 0.1) < 1e-9)   /* правильно: с точностью EPS */
```

## Короткое вычисление `&&` и `||`

Правая часть **не вычисляется**, если ответ уже ясен по левой:
- `a && b` — если `a` ложно, `b` не проверяется;
- `a || b` — если `a` истинно, `b` не проверяется.

Этим защищаются от ошибок: `if (n != 0 && s / n > 5)` — деления на ноль не будет.

## Оператор `switch`

Выбор по **целому** значению (или символу):

```c
switch (day) {
case 1: printf("понедельник\n"); break;
case 2: printf("вторник\n"); break;
/* ... */
case 6:
case 7: printf("выходной\n"); break;   /* 6 и 7 — одна ветка */
default: printf("нет такого дня\n");
}
```

> [!warning] Не забывай `break`
> Без `break` выполнение «проваливается» в следующий `case`. Иногда это используют специально (как `case 6: case 7:` выше), но чаще это ошибка.

## Тернарная операция `?:`

`условие ? значение1 : значение2` — короткий `if` внутри выражения:

```c
int max = (a > b) ? a : b;
printf("%s\n", (n % 2 == 0) ? "чётное" : "нечётное");
```

## Пример: квадратное уравнение

Решить $ax^2 + bx + c = 0$ при $a \ne 0$. Дискриминант $D = b^2 - 4ac$:
- $D < 0$ — корней нет;
- $D = 0$ — один корень $x = -\frac{b}{2a}$;
- $D > 0$ — два корня $x_{1,2} = \frac{-b \mp \sqrt{D}}{2a}$.

```c
#include <stdio.h>
#include <math.h>
#define EPS 1e-12

int main(void) {
    double a, b, c, d;
    scanf("%lf%lf%lf", &a, &b, &c);
    d = b * b - 4 * a * c;
    if (d < -EPS) {
        printf("нет корней\n");
    } else if (fabs(d) <= EPS) {
        printf("x = %.3f\n", -b / (2 * a));
    } else {
        printf("x1 = %.3f, x2 = %.3f\n", (-b - sqrt(d)) / (2 * a), (-b + sqrt(d)) / (2 * a));
    }
    return 0;
}
```

Заметь: дискриминант — вещественный, поэтому «равен нулю» проверяется с точностью `EPS`.
