## Итерационный цикл: когда число шагов заранее неизвестно

Во всех циклах до сих пор мы знали, сколько будет шагов. В **итерационном** цикле шаги повторяются, пока не достигнута нужная **точность**. Классический пример — вычисление функции через **бесконечный ряд**.

Например, экспонента раскладывается в ряд Тейлора:

$$
e^x = \sum_{k=0}^{\infty} \frac{x^k}{k!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \dots
$$

Ряд бесконечный, но его члены быстро уменьшаются. Складываем, пока очередной член по модулю не станет меньше заданной точности $\varepsilon$.

## Рекуррентная формула — ключ к задаче

Считать $x^k$ и $k!$ заново для каждого члена — медленно и опасно: $k!$ быстро переполняется. Вместо этого **следующий член получают из предыдущего**. Поделим $(k+1)$-й член на $k$-й:

$$
\frac{a_{k+1}}{a_k} = \frac{x^{k+1}/(k+1)!}{x^k/k!} = \frac{x}{k+1}
\quad\Rightarrow\quad
a_{k+1} = a_k \cdot \frac{x}{k+1}, \qquad a_0 = 1.
$$

Одно умножение и одно деление на каждом шаге.

```c
#include <stdio.h>
#include <math.h>

#define MAXK 1000     /* защита от бесконечного цикла */

int main(void) {
    double x, eps;    /* аргумент и точность */
    double a, s;      /* текущий член ряда и сумма */
    int k;            /* номер члена */

    scanf("%lf%lf", &x, &eps);
    a = 1.0;          /* a0 = 1 */
    s = 0.0;
    k = 0;
    while (fabs(a) >= eps && k < MAXK) {
        s = s + a;
        a = a * x / (k + 1);   /* рекуррентная формула */
        k++;
    }
    printf("S = %.10f, членов: %d, exp(x) = %.10f\n", s, k, exp(x));
    return 0;
}
```

При $x = 1$, $\varepsilon = 10^{-6}$ сумма $\approx 2.7182815$ (10 членов) — совпадает с `exp(1)` до шестого знака.

## Как вывести рекуррентную формулу самому

1. Выпиши общий член $a_k$ формулой.
2. Запиши $a_{k+1}$ (подставь $k+1$ вместо $k$).
3. Найди отношение $\frac{a_{k+1}}{a_k}$ и сократи факториалы и степени.
4. Найди $a_0$ (или $a_1$) — с него начинается цикл.

Пример для $\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$, общий член $a_k = \frac{(-1)^k x^{2k+1}}{(2k+1)!}$:

$$
\frac{a_{k+1}}{a_k} = -\frac{x^2}{(2k+2)(2k+3)}, \qquad a_0 = x.
$$

## Условия остановки

1. **Точность достигнута:** $\lvert a_k \rvert < \varepsilon$.
2. **Защита от бесконечного цикла:** номер члена достиг предела `MAXK` (например, если пользователь ввёл $\varepsilon = 0$).
3. (в ЛР №2) **Точность типа исчерпана:** `s + a == s` — член уже не меняет сумму `double`.

> [!warning] Точность ε — не погрешность результата
> Условие $\lvert a_k\rvert < \varepsilon$ гарантирует, что **отброшенный член** мал. Для знакочередующихся рядов (как $\sin x$) ошибка суммы действительно меньше первого отброшенного члена. Для рядов с положительными членами ошибка может быть больше $\varepsilon$ — это стоит упомянуть в анализе задачи.
