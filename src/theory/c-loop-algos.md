## Типовые алгоритмы — кирпичики любой программы

Почти любая задача на циклы собирается из нескольких шаблонов. Их нужно знать наизусть — как таблицу умножения. Те же шаблоны потом работают с массивами, строками и файлами.

## 1. Накопление суммы и произведения

```c
s = 0;                      /* сумма: начальное значение 0 */
p = 1;                      /* произведение: начальное значение 1 */
for (i = 1; i <= n; i++) {
    s = s + i;
    p = p * i;              /* p = n! */
}
```

## 2. Счётчик

```c
count = 0;
for (i = 1; i <= n; i++) {
    scanf("%d", &x);
    if (x > 0) count++;     /* считаем положительные */
}
```

## 3. Последовательность до «стоп-числа»

Числа вводятся, пока не встретится 0 (сам 0 не обрабатывается):

```c
scanf("%d", &x);
while (x != 0) {
    /* обработать x */
    scanf("%d", &x);        /* прочитать следующее */
}
```

Если признак конца — конец ввода (в файле или при перенаправлении), используют результат `scanf`:

```c
while (scanf("%d", &x) == 1) {
    /* обработать x */
}
```

## 4. Максимум и минимум

Первое число — текущий максимум, дальше сравниваем каждое следующее:

```c
scanf("%d", &x);
max = x;
while (scanf("%d", &x) == 1) {
    if (x > max) max = x;
}
```

> [!warning] Не начинай максимум с нуля
> `max = 0` сломается, если все числа отрицательные. Начинай с первого элемента.

## 5. Цифры числа

`n % 10` — последняя цифра, `n / 10` — число без неё. Повторяем, пока число не кончится:

```c
sum = 0; count = 0;
do {
    sum += n % 10;
    count++;
    n /= 10;
} while (n > 0);            /* do-while: у числа 0 тоже одна цифра */
```

Перевернуть число (1234 → 4321): `r = r * 10 + n % 10; n /= 10;`.

## 6. Проверка на простоту

Число $n \ge 2$ простое, если не делится ни на одно $d$ от 2 до $\sqrt n$:

```c
isPrime = (n >= 2);
for (d = 2; d * d <= n; d++) {
    if (n % d == 0) {
        isPrime = 0;
        break;              /* делитель найден — дальше проверять незачем */
    }
}
```

Почему до $\sqrt n$: если $n = a \cdot b$ и $a \le b$, то $a \le \sqrt n$. Условие `d * d <= n` — то же, что `d <= sqrt(n)`, но без вещественных чисел.

## 7. НОД — алгоритм Евклида

$\gcd(a, b) = \gcd(b, a \bmod b)$, пока $b \ne 0$:

```c
while (b != 0) {
    t = a % b;
    a = b;
    b = t;
}
/* ответ в a */
```

## 8. Флаг «есть ли хоть один» / «все ли»

```c
found = 0;                       /* есть ли хоть одно отрицательное */
allEven = 1;                     /* все ли чётные */
for (i = 0; i < n; i++) {
    scanf("%d", &x);
    if (x < 0) found = 1;
    if (x % 2 != 0) allEven = 0;
}
```

## 9. Числа Фибоначчи — «помним два предыдущих»

```c
a = 0; b = 1;                    /* F0, F1 */
for (i = 2; i <= n; i++) {
    c = a + b;
    a = b;
    b = c;
}
/* b = F(n) при n >= 1 */
```

> [!tip] Как выбрать тип
> Факториал и числа Фибоначчи растут очень быстро: $13!$ уже не помещается в `int`. Для них используй `long long` (до $20!$) — и помни, что любой тип конечен. Об этом — модуль 3.
