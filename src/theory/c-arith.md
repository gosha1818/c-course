## Арифметические операции

| Операция | Смысл | Пример | Результат |
|---|---|---|---|
| `+` `-` `*` | сложение, вычитание, умножение | `7 * 3` | `21` |
| `/` | деление | `7 / 2` и `7.0 / 2` | `3` и `3.5` |
| `%` | остаток от деления (только целые) | `7 % 2` | `1` |

## Целочисленное деление — главная ловушка

Если **оба** операнда целые, результат — тоже целое, дробная часть **отбрасывается** (не округляется!):

```c
printf("%d\n", 7 / 2);      /* 3 */
printf("%d\n", 1 / 3);      /* 0 */
printf("%d\n", -7 / 2);     /* -3: отбрасывание к нулю */
printf("%d\n", -7 % 2);     /* -1: знак остатка = знак делимого */
```

Чтобы получить дробный результат, хотя бы один операнд должен быть вещественным:

```c
int s = 7, n = 2;
double avg1 = s / n;            /* 3.0 — деление уже прошло в целых! */
double avg2 = (double)s / n;    /* 3.5 — явное приведение типа */
double avg3 = s * 1.0 / n;      /* 3.5 — тоже работает */
```

> [!danger] `double avg = s / n;` — не спасает
> Тип переменной слева не влияет на вычисление справа. Сначала считается `s / n` в целых (3), потом 3 превращается в 3.0.

## Остаток `%` — где пригождается

| Задача | Запись |
|---|---|
| чётность | `n % 2 == 0` |
| делится ли на k | `n % k == 0` |
| последняя цифра | `n % 10` |
| убрать последнюю цифру | `n / 10` |
| часы, минуты, секунды | `t / 3600`, `t % 3600 / 60`, `t % 60` |

Пример: трёхзначное число 472 → цифры `472 / 100 = 4`, `472 / 10 % 10 = 7`, `472 % 10 = 2`.

## Приоритет операций

Как в математике: сначала `*`, `/`, `%`, потом `+`, `-`; при равном приоритете — слева направо. Скобки меняют порядок.

```c
int x = 2 + 3 * 4;       /* 14 */
int y = (2 + 3) * 4;     /* 20 */
int z = 10 / 3 * 3;      /* 9: (10 / 3) * 3 = 3 * 3 */
```

## Сокращённые операции

| Запись | То же самое |
|---|---|
| `x += 5;` | `x = x + 5;` |
| `x -= 2;` `x *= 3;` `x /= 4;` `x %= 10;` | аналогично |
| `i++;` или `++i;` | `i = i + 1;` |
| `i--;` или `--i;` | `i = i - 1;` |

Разница между `i++` и `++i` видна, только если результат используется в выражении: `a = i++` — сначала присвоить старое `i`, потом увеличить; `a = ++i` — сначала увеличить. В отдельной строке `i++;` и `++i;` одинаковы.

> [!warning] Не меняй переменную дважды в одном выражении
> `i = i++ + ++i;` — неопределённое поведение: разные компиляторы дадут разный ответ. Одна строка — одно изменение переменной.

## Преобразование типов

- В выражении с `int` и `double` целое автоматически превращается в `double`: `5 + 2.5` → `7.5`.
- При присваивании `double` в `int` дробная часть **отбрасывается**: `int k = 3.99;` → `3`.
- Явное приведение: `(int)x`, `(double)n`.
- Округление до ближайшего: `(int)(x + 0.5)` для положительных или `round(x)` из `<math.h>`.

## Математические функции `<math.h>`

| Функция | Что считает |
|---|---|
| `sqrt(x)` | $\sqrt{x}$ |
| `pow(x, y)` | $x^y$ |
| `fabs(x)` | $\lvert x\rvert$ для `double` (для `int` — `abs` из `<stdlib.h>`) |
| `sin(x)`, `cos(x)`, `tan(x)` | тригонометрия, `x` в **радианах** |
| `exp(x)`, `log(x)`, `log10(x)` | $e^x$, $\ln x$, $\lg x$ |
| `floor(x)`, `ceil(x)`, `round(x)` | вниз, вверх, до ближайшего |

```c
#include <math.h>
#define PI 3.14159265358979

double r = 2.0;
double area = PI * r * r;                 /* r*r быстрее и точнее, чем pow(r, 2) */
double c = sqrt(3.0 * 3.0 + 4.0 * 4.0);   /* 5.0 */
double deg = 30.0;
double s = sin(deg * PI / 180.0);         /* 0.5: градусы → радианы */
```

> [!tip] `pow` — не для целых степеней в цикле
> `pow(2, 10)` возвращает `double` 1024.0. Для целых степеней и тем более в цикле лучше умножать: `p = p * x;`. Это быстрее и не даёт погрешностей вроде 999.9999.
