## Вывод: `printf`

`printf` печатает **строку формата**, в которую вместо **спецификаторов** `%…` подставляются значения:

```c
int n = 5;
double x = 3.14159;
printf("n = %d, x = %f\n", n, x);      /* n = 5, x = 3.141590 */
```

| Спецификатор | Тип | Пример вывода |
|---|---|---|
| `%d` | `int` | `-42` |
| `%u` | `unsigned int` | `42` |
| `%lld` | `long long` | `123456789012` |
| `%f` | `double` (и `float`) | `3.141590` (6 знаков после точки) |
| `%.2f` | `double`, 2 знака | `3.14` |
| `%e` | `double`, экспоненциальная форма | `3.141590e+00` |
| `%g` | `double`, короткая форма | `3.14159` |
| `%c` | `char` | `A` |
| `%s` | строка | `Hello` |
| `%x`, `%X`, `%o` | целое в 16-й / 8-й системе | `1f`, `1F`, `37` |
| `%p` | адрес (указатель) | `0x7ffd...` |
| `%%` | знак `%` | `%` |

**Ширина и выравнивание.** Число между `%` и буквой — минимальная ширина поля:

```c
printf("|%5d|\n", 42);      /* |   42|  выравнивание вправо */
printf("|%-5d|\n", 42);     /* |42   |  минус — влево */
printf("|%05d|\n", 42);     /* |00042|  дополнить нулями */
printf("|%8.3f|\n", 3.14159);   /* |   3.142| ширина 8, 3 знака */
```

Так строят ровные таблицы: `%-14s` для фамилии, `%5d` для числа.

> [!warning] Тип в формате должен совпадать с типом значения
> `printf("%d", 2.5)` напечатает мусор, а не 2: функция прочитает байты `double` как `int`. Компилятор часто предупреждает о таком — не игнорируй.

## Ввод: `scanf`

`scanf` читает значения с клавиатуры **по адресам** переменных — поэтому перед именем ставится `&` («адрес»):

```c
int n;
double x;
scanf("%d", &n);        /* прочитать целое */
scanf("%lf", &x);       /* прочитать double — именно %lf! */
scanf("%d%lf", &n, &x); /* два значения через пробел или Enter */
```

| Что читаем | Спецификатор `scanf` |
|---|---|
| `int` | `%d` |
| `long long` | `%lld` |
| `float` | `%f` |
| `double` | **`%lf`** (в `printf` для `double` — `%f`) |
| `char` | `" %c"` (с пробелом — пропустить пробелы и Enter) |
| слово в массив `char` | `%s` (без `&`, подробно — в модуле «Строки») |

> [!danger] Три главные ошибки со `scanf`
> 1. **Забыт `&`:** `scanf("%d", n)` — программа запишет число по случайному адресу и, скорее всего, упадёт.
> 2. **`%f` для `double`:** `scanf("%f", &x)` при `double x` запишет 4 байта из 8 — получится мусор. Для `double` всегда `%lf`.
> 3. **Нет проверки результата** — см. ниже.

## Проверка ввода

`scanf` **возвращает число успешно прочитанных значений**. Если пользователь ввёл буквы вместо числа, `scanf("%d", &n)` вернёт `0`, а буквы **останутся** в буфере ввода. Следующий `scanf` снова споткнётся о них — программа зациклится. Поэтому в лабораторных:

```c
if (scanf("%d", &n) != 1) {
    printf("Ошибка ввода: нужно целое число\n");
    return 1;      /* завершить программу с кодом ошибки */
}
```

`return 1;` в `main` завершает программу; код `1` (не ноль) сообщает операционной системе, что произошла ошибка.

## Символы: `getchar` и `putchar`

```c
int ch = getchar();     /* прочитать один символ (int — чтобы вместить и EOF) */
putchar(ch);            /* напечатать один символ */
putchar('\n');
```

> [!tip] Пробел перед `%c`
> После `scanf("%d", &n)` в буфере остаётся символ Enter (`'\n'`). `scanf("%c", &c)` прочитает именно его. `scanf(" %c", &c)` — с пробелом — сначала пропустит все пробелы и переводы строк.

## Пример: программа в стиле лабораторной

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main(void) {
    double a, b;    /* стороны прямоугольника */

    setlocale(LC_CTYPE, "Russian");

    printf("Введите стороны прямоугольника a и b: ");
    if (scanf("%lf%lf", &a, &b) != 2) {
        printf("Ошибка ввода: нужны два числа\n");
        return 1;
    }
    printf("Площадь: %.2f\n", a * b);
    printf("Периметр: %.2f\n", 2 * (a + b));
    return 0;
}
```

А вот так эта же программа выглядит **в тренажёре** (печатается только ответ):

```c
#include <stdio.h>

int main(void) {
    double a, b;
    scanf("%lf%lf", &a, &b);
    printf("%.2f %.2f\n", a * b, 2 * (a + b));
    return 0;
}
```
