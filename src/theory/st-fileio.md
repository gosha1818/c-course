## Практикум: типовые программы с файлами

### Прочитать все числа из файла

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main(void) {
    FILE *f = fopen("in.txt", "r");
    int x, count = 0;
    long long sum = 0;
    if (f == NULL) {
        printf("Не удалось открыть in.txt\n");
        return 1;
    }
    while (fscanf(f, "%d", &x) == 1) {   /* читаем, пока читается */
        sum += x;
        count++;
    }
    fclose(f);
    printf("%d чисел, сумма %lld\n", count, sum);
    return 0;
}
```

### Прочитать файл построчно

```c
char line[256];
int n = 0;
while (fgets(line, sizeof line, f) != NULL) {
    n++;
    printf("%3d: %s", n, line);          /* в line уже есть '\n' */
}
```

### Записать результат в файл

```c
FILE *out = fopen("out.txt", "w");      /* "w" стирает старое содержимое! */
if (out == NULL) { printf("Не удалось создать out.txt\n"); return 1; }
fprintf(out, "Сумма: %lld\n", sum);
fclose(out);                            /* без fclose данные могут не дописаться */
```

### Изменить файл «на месте» через временный

Текстовый файл нельзя изменить посередине: запись другой длины затрёт соседние строки. Поэтому:

1. читаем `F1.txt` и пишем новый вариант в `tmp.txt`;
2. закрываем оба файла;
3. `remove("F1.txt")` — удаляем старый;
4. `rename("tmp.txt", "F1.txt")` — новый занимает его место.

Если на шагах 1–2 случилась ошибка (неверная запись), старый файл не трогаем, а временный удаляем — так сделано в ЛР №6.

### Где лежат файлы в Visual Studio

При запуске из Visual Studio (Ctrl+F5) текущая папка — **папка проекта** (где лежит `main.c`), а не папка с `.exe`. Клади `F1.txt` туда. Если файл в кодировке Windows-1251 (как в ЛР №6), русские буквы читаются правильно после `SetConsoleCP(1251)`.

> [!info] Файлы в тренажёре
> В задачах с файлами тренажёр сам создаёт входные файлы рядом с программой перед запуском, а после — показывает содержимое выходных файлов под выводом на экран. В тренажёре кодировка UTF-8.
