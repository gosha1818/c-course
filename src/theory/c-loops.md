## Зачем циклы

Цикл повторяет блок команд, пока выполняется условие. Без циклов нельзя обработать 1000 чисел, не написав 1000 строк.

## Цикл `while` — «пока»

```c
while (условие) {
    /* тело: повторяется, пока условие истинно */
}
```

Условие проверяется **перед** каждым повтором. Если оно ложно с самого начала, тело не выполнится ни разу.

```c
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;              /* без этой строки цикл бесконечный! */
}
/* 1 2 3 4 5 */
```

## Цикл `for` — «для i от … до …»

Когда число повторений известно, удобнее `for`: все три части управления стоят в одной строке.

```c
for (инициализация; условие; шаг) {
    тело;
}

for (i = 1; i <= 5; i++) {
    printf("%d ", i);       /* 1 2 3 4 5 */
}
for (i = 10; i > 0; i -= 3) {
    printf("%d ", i);       /* 10 7 4 1 */
}
```

Порядок работы `for`: инициализация (один раз) → проверка условия → тело → шаг → проверка условия → тело → … Это то же самое, что:

```c
i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}
```

## Цикл `do … while` — «сделай, потом проверь»

```c
do {
    тело;
} while (условие);     /* точка с запятой обязательна */
```

Тело выполняется **хотя бы один раз**. Удобно для меню. В лабораторных курса принято обходиться без него — через `while` (см. «Ввод с проверкой» ниже).

## `break` и `continue`

- `break` — немедленно **выйти** из цикла.
- `continue` — пропустить остаток тела и перейти к **следующему** повтору.

```c
for (i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   /* чётные пропускаем */
    if (i > 7) break;           /* после 7 — стоп */
    printf("%d ", i);           /* 1 3 5 7 */
}
```

## Трассировка — проверяем цикл на бумаге

Таблица значений переменных на каждом шаге — лучший способ понять цикл и найти ошибку. Сумма $1 + 2 + 3$:

```c
s = 0;
for (i = 1; i <= 3; i++) s = s + i;
```

| Шаг | `i` до тела | условие `i <= 3` | `s` после тела |
|---|---|---|---|
| 1 | 1 | да | 1 |
| 2 | 2 | да | 3 |
| 3 | 3 | да | 6 |
| 4 | 4 | **нет** — выход | 6 |

## Вложенные циклы

Цикл внутри цикла: внутренний выполняется **полностью** на каждом шаге внешнего.

```c
for (i = 1; i <= 3; i++) {          /* строки */
    for (j = 1; j <= 4; j++) {      /* столбцы */
        printf("%4d", i * j);
    }
    printf("\n");
}
```

```output
   1   2   3   4
   2   4   6   8
   3   6   9  12
```

## Ввод с повторным запросом

В лабораторных число вне допустимого диапазона не должно ломать программу: её просят ввести снова. Если введено **не число** — сообщение и выход (иначе `scanf` будет вечно спотыкаться об одни и те же буквы):

```c
printf("Введите n (1 <= n <= %d): ", N);
if (scanf("%d", &n) != 1) {
    printf("Ошибка ввода\n");
    return 1;
}
while (n < 1 || n > N) {
    printf("Ошибка: n должно быть от 1 до %d. Введите заново: ", N);
    if (scanf("%d", &n) != 1) {
        printf("Ошибка ввода\n");
        return 1;
    }
}
```

> [!danger] Бесконечный цикл
> Цикл с условием обязан когда-нибудь закончиться. Перед тем как запустить, ответь себе: **какая переменная в теле меняется так, что условие станет ложным?** Если такой нет — цикл вечный.
