## Шаблон программы для лабораторной

```c
#define _CRT_SECURE_NO_WARNINGS   /* первой строкой: разрешить scanf, strcpy, fopen */

#include <stdio.h>
#include <locale.h>
#include <windows.h>              /* только если вводятся русские буквы */

#define N 50                      /* размеры массивов — только через #define */

int main(void) {
    int n;                        /* комментарий к каждой переменной */

    setlocale(LC_CTYPE, "Russian");   /* русский вывод; LC_CTYPE, чтобы точка осталась десятичной */
    SetConsoleCP(1251);               /* русский ввод */
    SetConsoleOutputCP(1251);

    printf("Введите n (1 <= n <= %d): ", N);
    if (scanf("%d", &n) != 1) {
        printf("Ошибка ввода\n");
        return 1;
    }
    while (n < 1 || n > N) {
        printf("Ошибка: введите заново: ");
        if (scanf("%d", &n) != 1) { printf("Ошибка ввода\n"); return 1; }
    }

    /* ... */
    return 0;
}
```

## Клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+F5 | запуск без отладки (консоль не закрывается) |
| F5 | запуск с отладкой / продолжить |
| F9 | точка останова |
| F10 / F11 | шаг с обходом / с заходом в функцию |
| Shift+F11 | выйти из функции |
| Shift+F5 | остановить отладку |
| Ctrl+Shift+B | собрать |
| Ctrl+K, Ctrl+C / Ctrl+K, Ctrl+U | закомментировать / раскомментировать выделенное |
| Ctrl+K, Ctrl+D | выровнять отступы во всём файле |

## Частые проблемы

| Проблема | Решение |
|---|---|
| ошибка C4996 про `scanf` | `#define _CRT_SECURE_NO_WARNINGS` первой строкой |
| «кракозябры» вместо русского текста | `setlocale(LC_CTYPE, "Russian")`; файл сохранить в «UTF-8 с сигнатурой» |
| русские буквы при вводе читаются неправильно | `SetConsoleCP(1251); SetConsoleOutputCP(1251);` |
| `scanf("%lf")` не читает `3.14` | вместо `LC_ALL` используй `LC_CTYPE` |
| «выражение должно иметь константное значение» для `int a[n]` | размер массива — `#define N 100`, реальное количество — в переменной |
| файл компилируется как C++ | переименуй `main.cpp` в `main.c` |
| программа не видит `F1.txt` | файл должен лежать в папке проекта (рядом с `.c`), а не рядом с `.exe` |
