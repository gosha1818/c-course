## Как нарисовать блок-схему в draw.io

[draw.io](https://app.diagrams.net) — бесплатный редактор схем, работает в браузере и как программа для Windows. В нём удобно рисовать схемы по ГОСТ 19.701-90.

1. Открой [app.diagrams.net](https://app.diagrams.net) → «Создать новую диаграмму» → «Пустая диаграмма». Место сохранения — «Устройство» (файл `.drawio` на компьютере).
2. Слева в библиотеке фигур открой раздел **«Блок-схема» (Flowchart)**. Если его нет — «Ещё фигуры…» внизу → отметь «Блок-схема».
3. Перетаскивай фигуры, соединяй их линиями (наведи на фигуру — появятся синие стрелки).
4. **Файл → Экспорт как → PNG** (масштаб 200–300 %, «Прозрачный фон» выключен) или **SVG** — и вставь в Word с подписью «Рисунок N — …».

### Какие фигуры брать

| Блок по ГОСТ | Фигура в draw.io | Для чего |
|---|---|---|
| Терминатор | Terminator (скруглённый прямоугольник) | «Начало», «Конец», заголовок подпрограммы, «Возврат» |
| Процесс | Process (прямоугольник) | вычисления, присваивания |
| Данные | Data (параллелограмм) | ввод и вывод |
| Решение | Decision (ромб) | условие; выходы подписать «да» / «нет» |
| Подготовка | Preparation (шестиугольник) | заголовок цикла `for`: «i = 0, n−1» |
| Предопределённый процесс | Predefined Process (прямоугольник с двойными боковыми линиями) | вызов своей подпрограммы |
| Соединитель | Connector (кружок с буквой/цифрой) | разрыв линии, переход на другую страницу |

### Правила, которые проверяют

- Схема читается **сверху вниз и слева направо**; стрелки рисуют, только если поток идёт в другую сторону (возврат к началу цикла, обход).
- Один вход («Начало» или заголовок подпрограммы) и один выход («Конец» или «Возврат»).
- У ромба подписаны выходы «да» и «нет».
- Размеры блоков одинаковые: высота $a$, ширина $b = 1{,}5a$ (по ГОСТ $a$ выбирают из ряда 10, 15, 20 мм…). В draw.io: выдели все блоки → справа «Расположение» → одинаковые ширина и высота, например 120 × 80.
- Текст в блоке — **в терминах задачи**: «найти максимум строки i», а не `for (j = 0; j < m; j++)`.
- Для работы «Подпрограммы» — отдельная схема для основной программы и для **каждой** подпрограммы.

> [!tip] Цикл `for` двумя способами
> По ГОСТ цикл со счётчиком рисуют блоком «Подготовка» (шестиугольник) с границами цикла: тело — снизу, линия возврата — слева, выход — справа. Цикл `while` — ромбом с условием и линией возврата к нему. Как делать в отчёте — смотри схемы ЛР №5 и ЛР №6 и уточни у преподавателя.

### Альтернативы

- **Microsoft Visio** — если есть лицензия; шаблон «Простая блок-схема».
- **Фигуры Word** (Вставка → Фигуры) — подходит для схем из 5–7 блоков, но неудобно править.
