| **Visual Studio Community** (2022 или новее) | писать, запускать и отлаживать программы; в ней программу проверяют на защите | да |

> [!info] Почему именно Visual Studio
> Курс и лабораторные рассчитаны на Visual Studio под Windows: преподаватель запускает программу именно там. Отсюда несколько особенностей кода, которые встречаются в каждой программе курса, — они собраны ниже в «шаблоне программы».

## Установка Visual Studio

1. Скачай **Visual Studio Community** с [visualstudio.microsoft.com](https://visualstudio.microsoft.com/ru/vs/community/) — она бесплатная.
2. В установщике отметь рабочую нагрузку **«Разработка классических приложений на C++»**. Отдельного пункта «C» нет: компилятор C входит в этот набор.
3. Установка займёт 10–30 минут и 5–8 ГБ на диске.

## Первый проект на C

1. **Файл → Создать → Проект** → шаблон **«Пустой проект»** (язык C++, платформа Windows). Назови проект, например, `lab1`.
2. В **Обозревателе решений** нажми правой кнопкой на папку **«Исходные файлы» → Добавить → Создать элемент…**
3. Выбери «Файл C++ (.cpp)», но в поле имени напиши **`main.c`** — с расширением **`.c`**.
4. Вставь код программы и нажми **Ctrl+F5** («Отладка → Запуск без отладки»). Окно консоли не закроется сразу — можно прочитать результат.

> [!warning] Расширение `.c`, а не `.cpp`
> По расширению Visual Studio решает, каким языком компилировать файл. Файл `.cpp` компилируется как **C++**: там другие правила (например, `const int` можно использовать как размер массива, а в C — нельзя). Лабораторные пишутся на **C** — значит, файл `main.c`.

## Шаблон программы для курса

```c
#define _CRT_SECURE_NO_WARNINGS   /* 1. иначе Visual Studio запретит scanf, strcpy, fopen */

#include <stdio.h>                /* printf, scanf */
#include <locale.h>               /* setlocale */

int main(void) {
    setlocale(LC_CTYPE, "Russian");   /* 2. русский текст в консоли */

    printf("Привет, мир!\n");

    return 0;
}
```

Разберём особенности, которые нужны **во всех** программах курса.

**1. `#define _CRT_SECURE_NO_WARNINGS` — первой строкой.** Visual Studio считает `scanf`, `strcpy`, `fopen` «небезопасными» и выдаёт ошибку C4996 с советом использовать `scanf_s`. Функции `_s` есть только у Microsoft, а в курсе пишем стандартный C. Эта строка отключает проверку. Она должна стоять **до** всех `#include`.

**2. Русский вывод — `setlocale(LC_CTYPE, "Russian");`.** Без неё вместо русских букв в консоли будут «кракозябры». Почему `LC_CTYPE`, а не `LC_ALL`? `LC_ALL` меняет ещё и формат чисел: десятичным разделителем станет запятая, и `scanf("%lf")` перестанет понимать `3.14`.

**3. Русский ввод — ещё две строки.** Если программа *читает* русские буквы с клавиатуры (строки в ЛР №4, фамилии в ЛР №6), добавь:

```c
#include <windows.h>
/* ... в начале main: */
SetConsoleCP(1251);         /* кодировка ввода */
SetConsoleOutputCP(1251);   /* кодировка вывода */
```

**4. Кодировка файла — UTF-8 с BOM.** Тогда Visual Studio правильно переводит русские строки программы в кодировку консоли Windows-1251. Если в консоли всё равно «кракозябры», пересохрани файл: **Файл → Сохранить как → стрелка у кнопки «Сохранить» → «Сохранить с кодировкой…» → «Юникод (UTF-8 с сигнатурой)»**.

**5. Размер массива — только `#define`.** Компилятор C в Visual Studio не принимает `const int N = 10;` как размер массива и не поддерживает массивы переменной длины `int a[n];`. Пиши `#define N 10`.

> [!tip] Русские буквы в Windows-1251
> В консоли Windows каждая русская буква — **один байт**: «А»…«Я» — коды 192…223, «а»…«я» — 224…255, «Ё» и «ё» стоят отдельно (168 и 184). Тип `char` в Visual Studio **знаковый**, поэтому код «а» в `char` — это −32. Это понадобится в ЛР №4.

## Запуск: Ctrl+F5 и F5

| Клавиши | Что делает |
|---|---|
| **Ctrl+F5** | собрать и запустить **без отладки**; консоль ждёт нажатия клавиши |
| **F5** | запустить **с отладкой**: останавливается на точках останова |
| **Ctrl+Shift+B** | только собрать (проверить, что нет ошибок) |
| **F9** | поставить/убрать точку останова на строке |

Если программа запущена через F5 и окно консоли сразу закрывается, это нормально: программа закончилась. Запускай через Ctrl+F5 или поставь точку останова на `return 0;`.

> [!note] Вместо `system("pause")`
> В старых примерах в конце `main` пишут `system("pause");`, чтобы окно не закрывалось. Это зависит от Windows и не нужно, если запускать через Ctrl+F5. Тренажёр этого курса такую строку просто пропустит.

## Альтернативы (если нет Windows)

- **VS Code + gcc** (MinGW-w64 / MSYS2 на Windows, `gcc` на Linux и macOS) — смотри видео selfedu №2 в этом уроке. Компилировать: `gcc -Wall -std=c11 main.c -o main -lm`.
- **Онлайн**: [OnlineGDB](https://www.onlinegdb.com/online_c_compiler) (есть отладчик и ввод с клавиатуры), [Compiler Explorer](https://godbolt.org).

Перед сдачей лабораторной всё равно проверь программу в Visual Studio: `_CRT_SECURE_NO_WARNINGS`, `#define` для размеров и кодировку русских букв.
