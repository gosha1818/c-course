## Переменная — именованная ячейка памяти

**Переменная** — участок оперативной памяти, у которого есть **имя**, **тип** и **значение**. Тип говорит компилятору, сколько байт отвести и как понимать эти байты: как целое число, как дробное или как символ.

```c
int age;            /* объявление: отвести 4 байта под целое число */
age = 19;           /* присваивание: записать в ячейку 19 */
int year = 2026;    /* объявление с инициализацией */
double price = 99.5, discount = 0.1;   /* несколько переменных одного типа */
```

> [!warning] Неинициализированная переменная содержит мусор
> `int s;` не делает `s` равной нулю. В ячейке лежит то, что осталось от прошлых программ. Поэтому перед накоплением суммы **всегда** пиши `s = 0;`.

## Основные типы

| Тип | Размер (Visual Studio) | Что хранит | Пример |
|---|---|---|---|
| `char` | 1 байт | символ (его код) или маленькое целое −128…127 | `'A'`, `'7'`, `'\n'` |
| `short` | 2 байта | целое −32 768…32 767 | `1000` |
| `int` | 4 байта | целое ≈ ±2,1 млрд (−2 147 483 648…2 147 483 647) | `-42` |
| `long` | 4 байта (в Linux — 8!) | целое | `100000L` |
| `long long` | 8 байт | целое ≈ ±9,2·10¹⁸ | `123456789012LL` |
| `float` | 4 байта | вещественное, 7–8 верных цифр | `3.14f` |
| `double` | 8 байт | вещественное, 15–16 верных цифр | `3.14`, `1e-6` |

- **`unsigned`** перед целым типом убирает знак и удваивает положительный диапазон: `unsigned int` — 0…4 294 967 295.
- Для дробных чисел в курсе используют **`double`**, не `float`: точнее и именно его ждёт `scanf("%lf")`.
- Почему у типов именно такие диапазоны и что будет при выходе за них — тема модуля 3 «Числа в памяти».

## Имена переменных

- Буквы латиницы, цифры и `_`; начинается не с цифры: `sum`, `max_value`, `x1`.
- Регистр важен: `Sum` и `sum` — разные переменные.
- Нельзя использовать **ключевые слова**: `int`, `for`, `return`, `if`, `while`…
- Имя должно говорить, что хранится: `count`, а не `k2`.

## Литералы — значения прямо в коде

| Запись | Тип | Значение |
|---|---|---|
| `42`, `-7` | `int` | целое |
| `42LL` | `long long` | целое 8 байт |
| `3.0`, `2.5`, `.5` | `double` | вещественное |
| `1e-6`, `2.5E3` | `double` | $10^{-6}$, $2500$ |
| `0x1F` | `int` | шестнадцатеричное 31 |
| `'A'` | `char` (код 65) | символ в **одинарных** кавычках |
| `"A"` | строка | **двойные** кавычки: массив из `'A'` и `'\0'` |

> [!tip] `5` и `5.0` — разные вещи
> `5` — целое, `5.0` — вещественное. От этого зависит результат деления: `5 / 2` равно `2`, а `5.0 / 2` равно `2.5` (подробно — в уроке «Арифметика»).

## Константы через `#define`

```c
#define N 50          /* максимальный размер массива */
#define EPS 1e-9      /* точность сравнения вещественных */
#define PI 3.14159265358979
```

Препроцессор заменяет `N` на `50` по всему тексту **до** компиляции. Точку с запятой после `#define` не ставят, имена пишут заглавными.

## Символ — это число

`char` хранит **код** символа в таблице ASCII (латиница, цифры, знаки) или Windows-1251 (русские буквы). С символами можно считать:

```c
char c = 'A';            /* код 65 */
printf("%c %d\n", c, c);         /* A 65 */
printf("%c\n", c + 1);           /* B — следующая буква */
char d = '7';
int digit = d - '0';             /* 7: цифра из символа-цифры */
```

| Символы | Коды ASCII |
|---|---|
| `'0'` … `'9'` | 48 … 57 |
| `'A'` … `'Z'` | 65 … 90 |
| `'a'` … `'z'` | 97 … 122 |
| пробел | 32 |

## Оператор `sizeof`

`sizeof(тип)` или `sizeof(переменная)` — сколько **байт** занимает тип или переменная. Результат имеет тип `size_t`; для печати удобно привести к `int`:

```c
printf("%d %d %d\n", (int)sizeof(char), (int)sizeof(int), (int)sizeof(double));   /* 1 4 8 */
```

## Обмен значений двух переменных

Классическая задача: поменять местами `a` и `b`. Запись `a = b; b = a;` не работает — после первой строки старое значение `a` потеряно. Нужна **третья** переменная:

```c
int a = 3, b = 7, tmp;
tmp = a;    /* tmp = 3 */
a = b;      /* a = 7 */
b = tmp;    /* b = 3 */
```

Этот приём понадобится в сортировке массивов (модуль 4).
