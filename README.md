# Курс C пошагово

**Открыть курс: https://gosha1818.github.io/c-course/**

Пошаговый курс программирования на языке C для первого курса — от первой программы до структур и файлов. Построен по материалам дисциплины «Информационные технологии и основы программирования» (НГТУ): лекции 1–5, методичка «Методы программирования», лабораторные работы № 2–6.

**Что внутри:** 8 модулей, 52 урока, 5 лабораторных работ, 365 вопросов, 141 задача с автопроверкой (из них 34 прикладные), 171 видео и видеофрагмент, ИИ-наставник, итоговый экзамен.

## Как устроено обучение

- **Урок = цели → видео → конспект → тест → практика.** Урок засчитывается, когда тест сдан на 80 % и решены обязательные задачи; только тогда открывается следующий.
- **Обязательные интервальные повторения.** После урока повторение ставится через 1 день, затем через 3, 7, 14, 30, 60 и 120 дней. Пока есть повторения на сегодня, новые уроки закрыты. Ошибка на повторении возвращает тему на завтра.
- **Задачи с автопроверкой.** Код компилируется gcc на сервере [Compiler Explorer](https://godbolt.org) и прогоняется на тестах прямо из браузера. Код под Visual Studio (`windows.h`, `system("pause")`, `scanf_s`) принимается как есть. Есть задачи с файлами.
- **Лабораторные как на занятии:** допуск по контрольным вопросам → ход работы по разделам отчёта → автопроверка ядра программы → образец решения → чек-лист отчёта и вопросы к защите. Шаблон отчёта Word: [`assets/labs/report-template.docx`](assets/labs/report-template.docx).
- **Видео — только нужный кусок.** Длинные лекции (CS50 на русском, семинары МФТИ К. Владимирова и Т. Хирьянова, selfedu, Alek OS, тренировки Яндекса) встроены фрагментами с нужной минуты до нужной.
- **Прикладные задачи** в уроках: кредит, алгоритм Луна, подсеть IPv4, права доступа, «Жизнь», «Сапёр», шифр Виженера, читаемость текста, телефонная книга, банк и другие (часть — по мотивам CS50 и MIT 6.087).
- **ИИ-наставник** открывается в задаче, только если ученик застрял: не меньше 3 неудачных проверок, все подсказки открыты и 30 минут работы. Он указывает на ошибку и задаёт наводящий вопрос, но не пишет решение. Нейросеть бесплатная: в браузере (WebLLM), локально (Ollama) или по API со своим ключом (Groq, OpenRouter, Gemini).
- **Прогресс** хранится в браузере (localStorage), есть сохранение в файл и загрузка.

## Запуск локально

Сайт статический, сборка нужна только после правки содержимого.

```bash
npm install            # один раз: marked, katex, highlight.js, docx
npm run serve          # http://localhost:8080
```

Открывать `index.html` двойным щелчком тоже можно, но встроенные видео YouTube с `file://` не воспроизводятся — используй `npm run serve` или GitHub Pages.

## Как править курс

| Что | Где |
|---|---|
| Модули, уроки, тесты, задачи, видео | `src/content/00-start.mjs` … `07-files.mjs` |
| Справочник, ресурсы, экзамен | `src/content/extra.mjs` |
| Прикладные задачи по урокам | `src/content/applied.mjs` |
| Фрагменты видео и доп. ссылки по урокам | `src/content/clips.mjs` |
| Конспекты лекций (исходник) | `src/source/itiop.md` — уроки ссылаются на его разделы по заголовкам |
| Дополнительная теория | `src/theory/*.md` |
| Интерфейс | `index.html`, `css/style.css`, `js/*.js` |

```bash
npm run build          # собрать data/ из src/
npm run check          # собрать и прогнать эталонные решения всех задач на Godbolt
node tools/make-template.mjs   # пересобрать шаблон отчёта .docx
```

У каждой задачи есть эталонное решение. `npm run check` запускает его на всех тестах: если ожидаемый ответ не указан, он берётся из эталона, если указан — сверяется с ним.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и отправь туда содержимое этой папки (`git push`).
2. **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту курс будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Папка `data/` уже собрана и лежит в репозитории, поэтому GitHub Actions не нужны.
